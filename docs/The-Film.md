# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. Ten places user one has not seen. Then the stake: Every star is almost equally likely. What can you recommend from noise?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the race: Item mean 1.403, User kNN 1.384, SVD rank 2 1.384, Item kNN 1.382, Global mean 1.363; Global mean wins, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. User 1, then user 42: ten picks each Nature, Bandung, under 20k: with reasons Ratings are noise; the catalogue carries it
4. **The answer** (68 to 90 s): 0.008, correlation · user stars vs the public rating · the ratings are noise. And it ships. One limit: Lat/Long unused. No 'near me' route yet. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
